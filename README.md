# portofoliomery
DESKRIPSI PRODUK

1. Nama Produk

Mery Personal Portfolio Website

2. Fungsi Utama

Mery Personal Portfolio Website merupakan website yang dirancang untuk menyajikan informasi profil, kompetensi, pengalaman, serta hasil proyek pengembang dalam bentuk digital yang terstruktur dan mudah diakses.

3. Manfaat bagi Pengguna

- Memberikan informasi mengenai profil dan kompetensi pengembang secara profesional.
- Menjadi media untuk menampilkan berbagai proyek dan hasil karya.
- Memudahkan pengguna dalam memperoleh informasi mengenai kemampuan pengembang.
- Menjadi sarana digital untuk membangun personal branding.
- Memudahkan pengguna mengakses informasi melalui satu tautan website.

4. Cara Instalasi

Website merupakan aplikasi berbasis web yang dapat diakses tanpa proses instalasi pada perangkat pengguna.

Langkah penggunaan:

1. Pastikan perangkat terhubung ke internet.
2. Buka browser seperti Google Chrome atau browser lainnya.
3. Masukkan alamat website:
   https://cantikamerry7-ship-it.github.io/portofoliomeryimut/
4. Website dapat langsung digunakan dan seluruh informasi dapat diakses melalui menu yang tersedia.
